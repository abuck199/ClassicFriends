# Classic Friends

Brings back the Classic Era friends list in WoW Forever, instead of the new social window.

- Classic Era look
- Search by name, BattleTag, class or zone
- Faction and class colors
- Friends / Who / Guild / Raid tabs
- Double-click a friend to whisper
- Minimap button

Type `/cfriends` for the settings.

Found a bug or have an idea? [Open an issue](https://github.com/abuck199/ClassicFriends/issues).
